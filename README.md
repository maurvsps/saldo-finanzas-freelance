# Saldo · Finanzas freelance

Panel personal para organizar clientes, encargos recurrentes, ingresos mensuales, saldos en varias monedas y simulaciones de retiro.

## Abrir

Abre `index.html` en un navegador moderno. No requiere instalación. Los datos y cambios se guardan en el almacenamiento local del navegador; usa el botón de descarga para guardar un respaldo JSON.

## Privacidad y datos

La aplicación empieza vacía. Registra tus propios saldos, clientes y encargos desde el navegador. Todo queda en el almacenamiento local de ese navegador; no se envía a un servidor. Al cambiar de dominio o dispositivo, usa **Exportar respaldo** y luego **Importar respaldo** para mover tus datos.

Las cotizaciones de inicio son referenciales y editables. La proyección semanal cuenta las ocurrencias reales del día elegido dentro de cada mes.
